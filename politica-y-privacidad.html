2. Datos que podemos recibir

Dependiendo de la forma de contacto utilizada, podemos recibir datos como:

  • Nombre y apellido.
  • Número de teléfono.
  • Dirección de correo electrónico.
  • Domicilio o ubicación del trabajo solicitado.
  • Información proporcionada voluntariamente por el usuario sobre el servicio requerido.
  • Datos necesarios para elaborar un presupuesto o coordinar una visita.

Se recomienda no enviar mediante formularios información personal que no sea necesaria para la consulta o contratación.

3. Finalidad

Los datos podrán utilizarse para:

  • Responder consultas.
  • Elaborar presupuestos.
  • Coordinar visitas.
  • Coordinar trabajos.
  • Contactar al cliente.
  • Gestionar solicitudes de servicios.
  • Atender reclamos.
  • Cumplir obligaciones legales cuando corresponda.

4. Comunicación de datos

Los datos personales no serán vendidos ni comercializados.

Podrán ser comunicados a terceros únicamente cuando resulte necesario para prestar un servicio solicitado, cumplir una obligación legal o cuando el usuario haya autorizado dicha comunicación.

5. Seguridad

Se adoptarán medidas razonables destinadas a proteger los datos personales frente a accesos, modificaciones, divulgaciones o usos no autorizados.

No obstante, ningún sistema de transmisión o almacenamiento de información por Internet puede garantizar seguridad absoluta.

6. Derechos del titular de los datos

El titular de los datos puede ejercer los derechos que le reconoce la legislación argentina respecto del acceso, actualización, rectificación o eliminación de sus datos cuando corresponda.
